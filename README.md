# crumbz

Red social gastronómica para Venezuela: descubre dónde comer, publica tus visitas y arma tus rankings.

Monorepo con app móvil (Expo), web pública (Next.js) y backend en Supabase.

```bash
pnpm install
pnpm dev
```
